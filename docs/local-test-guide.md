# Local testing

Start with the [short MVP demo guide](demo-guide.md).

```bash
./start.sh
```

The startup terminal shows the visitor/admin URLs and private sign-in details. Complete the booking → payment → check-in → ride → reports walkthrough in the guide.

For automated checks:

```bash
./start.sh test
```

Optional infrastructure/failure demonstrations are in [advanced local testing](advanced-local-testing.md). They are separate from the MVP demo.
