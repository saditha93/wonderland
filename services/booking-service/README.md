# booking-service

Phase 2 PostgreSQL-backed service. See app/routes.py, SQL migrations and root docs/development.md. Configuration/middleware/auth/database handling is shared through wonderland_common but each service remains its own process/image. Public catalog/tier endpoints need no identity; protected mutations/history require signed local developer tokens until Cognito Phase 3. /health and /health/live check the process; /health/ready checks database/schema revision and returns 503 if unavailable. Default authentication fails closed; no AWS/payment credentials are bundled. Actual Docker and cloud execution remain unverified.
